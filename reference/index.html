Site built with quartodown and Quarto.

build_site( path = ".", tooltips = TRUE, freeze = FALSE, quiet = TRUE, devel = FALSE, preview = interactive() )Builds the package website into docs/ with Quarto.
preview_site(path = ".")Serves docs/, as built by build_site(), in a web browser, and reloads the page when the site is rebuilt.
use_quartodown(path = ".")Writes _quartodown.yml, the configuration file build_site() reads, at the package root.
use_quartodown_action(path = ".", overwrite = FALSE)Writes .github/workflows/quartodown.yaml, a GitHub Actions workflow that builds the site and deploys it to the gh-pages branch.
